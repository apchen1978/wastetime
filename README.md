# 浪費時間 (Waste Time)

一個認真浪費時間的點擊/放置（idle clicker）小遊戲。

> **重建背景**：本專案原為以 Gemini + Project IDX 製作的同名小遊戲，因雲端工作區遺失而無法找回原始碼。此版本於 2026-08-19 依原玩法（點擊/放置類）完整重建，並沿用創作者另一款遊戲 SIGNAL//RIFT 的暗色科技視覺語言。

## 玩法

- 點擊中央時鐘：浪費 1 秒（可升級為加倍），帶 Q 彈擠壓、霓虹漣漪與隨機飄字回饋。
- 購買「時間浪費器」：發呆、滑手機、追劇、通勤塞車、無意義會議、熬夜修仙、刷短影音、網路閒逛、人生迷惘、時間黑洞，每秒自動浪費更多時間。
- 時鐘指針會隨每秒產量（CPS）加速旋轉，產量越高轉得越瘋狂。
- 達成里程碑解鎖成就：浪費 1 分鐘、1 小時、1 天……一直到 1 年。
- **關卡系統**：累積時間跨過門檻（1 分鐘/1 小時/1 天/1 週/1 月/1 年/10 年/100 年/1000 年）即升級，每升一級時間流速 ×2；每一關換全新背景與按鈕風格（共 8 套主題：原點/深空/霓虹玫瑰/琥珀/薄荷/熔岩/極光/時間深處）。
- 畫面上會隨機飄出「摸魚」氣泡，點擊觸發 5 秒的 7 倍浪費狂熱，畫面外框閃爍金光。
- 離開遊戲期間，時間會繼續偷偷浪費（上限 8 小時）。

## 執行方式

零依賴、單一檔案，兩種方式皆可：

```bash
# 方式一：直接雙擊 index.html（瀏覽器開啟即可玩）
# 方式二：本機伺服器（若需從其他裝置存取）
node serve.mjs            # 預設 http://localhost:8080
```

進度（浪費時間、升級、成就）自動存於瀏覽器 localStorage。

## 技術

- 原生 HTML + CSS + JavaScript（ES5 風格，無建置、無框架、無外部資源）
- WebAudio 音效（可於右上角關閉）
- 響應式版面：桌面雙欄座艙，行動版單欄
